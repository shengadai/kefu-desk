# 快回 · 客服快捷回复桌面版

这是一个基于 Electron、React 和 TypeScript 的快捷回复工具，支持 Windows 桌面版与 Android 版。

## 当前功能

- 话术新增、编辑、删除、收藏和分类；支持公司、小组、私人范围标记。
- 按内容、标题、标签、分类搜索，支持汉字拼音及首字母检索。
- `Ctrl + Shift + Space` 呼出置顶浮窗；每条话术可选择 `Alt` 或 `Ctrl` + `1–9` 快捷复制。
- 浮窗可切换“最近使用自动置顶”或“固定顺序”；主界面和浮窗均支持拖动话术排序，固定顺序在本机保存并保持一致。
- 话术支持纯文字、纯图片、图片+文字；图片附件可添加任意数量，复制后回到聊天软件手动粘贴。
- 话术可添加多个视频附件，单个不超过 50 MB；视频可在客服宝内预览，复制时会将视频文件放入系统剪贴板，供支持文件粘贴的聊天窗口使用。
- 支持 `Ctrl + A` 全选当前筛选结果并批量删除、合并复制；支持深色主题和标签管理。
- 支持 `.xlsx` 表格导入导出、JSON 备份和 ZIP 完整备份；JSON 保留文字和图片，ZIP 另外打包视频附件，可完整恢复。
- JSON 导入先展示差异预览：按标题、文字和图片去重，重复项跳过并保留现有内容；可勾选新增项、查看原文对比，确认后合并，不覆盖或删除原话术。同名同范围的分类会复用，编号冲突会自动分配新编号。
- 数据保存在本机用户目录，离线可用；主窗口和浮窗共享本地话术库。
- 支持坚果云 WebDAV 同步话术、分类、图片和视频；视频文件与话术 JSON 分开保存，云端视频存放在 `客服宝/videos/`。
- 云端工作区以坚果云为主库，软件单独改动自动上传，云端改动自动拉取，其他设备可设为只读。
- 坚果云第三方应用密码使用 Windows 系统安全存储加密；并发编辑时以坚果云版本为准，并在覆盖本机云端缓存前保留备份。

## 坚果云同步

1. 在坚果云安全选项中创建一个第三方应用密码。
2. 在桌面应用点击连接坚果云，填写 WebDAV 地址、账号邮箱和第三方应用密码。
3. 在主电脑选择“主电脑”并首次连接；应用会验证账号，在坚果云 WebDAV 根目录创建客服宝文件夹并登记主设备。首次连接已有云端同步文件时，云端内容优先；本机云端缓存与云端内容不一致时会先备份缓存。
4. 其他设备选择“只读查看和复制”连接；这些设备不会上传话术，且应用会在本机拒绝新增、编辑、删除、收藏和导入。

`sync-v1.json` 保存话术信息和视频引用；图片继续保存在话术数据中，视频文件单独存放于 `客服宝/videos/`，单个文件最大 50 MB。主设备新增或编辑视频话术后会自动上传视频文件和话术引用；只读设备同步后下载并缓存视频。主设备上新增、编辑、删除会自动推送；云端发生新增、编辑、删除后，同步会更新本机云端工作区。双方同时修改同一条目时以云端为准，本机冲突缓存会备份在本机用户数据目录；如果云端同步文件意外丢失，应用会暂停而不会用旧缓存自动重建覆盖。断开同步不会删除本机或云端文件。

导出的 `.json` 不包含视频数据；需要连视频一起迁移或恢复时，请使用“ZIP 完整备份”。导入普通 JSON 会先展示待新增内容和重复数量，确认勾选后只合并新增文字和图片，并忽略其中可能存在的视频引用。仅有视频引用、没有文字和图片的记录不会作为空话术导入；已有视频话术保持原样。取消导入或全部重复时不改变话术库。ZIP 仍用于完整恢复，不受 JSON 合并导入规则影响。

设备权限由客服宝客户端按云端主设备标记执行，不等于坚果云服务端的团队 ACL。使用同一坚果云凭据的人仍可绕过客服宝，直接修改坚果云中的同步文件；不要把应用只读模式当作抵御云盘账号持有者的安全隔离。

## Android 版

- Android 版包含本机工作区、坚果云云端工作区、搜索/分类/复制，以及蓝发鲸鱼系统悬浮宠物；在设置中开启宠物并授予“显示在其他应用上层”权限后，点击宠物打开原生话术面板。
- Android 设备固定为只读同步端：可查看、搜索和复制坚果云话术，编辑仍在主电脑完成。首次使用需在手机上输入坚果云账号和第三方应用密码；密码使用 Android Keystore 加密保存。
- 文字与图片会复制到 Android 系统剪贴板，JSON/XLSX 可通过系统分享面板导出。Android 暂不支持新增或播放视频附件；已同步的话术中的视频引用会保留。
- 安装依赖 Android Studio、Android SDK 和 Gradle 所需的 JDK。准备好工具链后运行 `npm install`、`npm run build`、`npx cap sync android`，然后在 Android Studio 打开 `android/` 工程运行或生成 APK。仅运行 `npm run build` 不会生成 APK。

## 开发与打包

```sh
npm install
npm run dev
npm run build
npm run dist
```

Windows 安装包输出到 `release/`。
